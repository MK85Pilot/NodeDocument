# 配置选项

NodePass采用极简方法进行配置，所有设置都通过命令行参数和环境变量指定。本指南说明所有可用的配置选项，并为各种部署场景提供建议。

## 日志级别

- `none`：禁用日志记录
- `debug`：详细调试信息
- `info`：一般操作信息(默认)
- `warn`：警告条件
- `error`：错误条件
- `event`：事件记录

```bash
nodepass server://0.0.0.0:10101/0.0.0.0:8080?log=debug
```

## TLS加密模式

- **模式0**：无TLS加密（明文TCP/UDP）
- **模式1**：自签名证书（自动生成）
- **模式2**：自定义证书（需要`crt`和`key`参数）

```bash
# TLS模式1示例（自签名）
nodepass server://0.0.0.0:10101/0.0.0.0:8080?tls=1

# TLS模式2示例（自定义证书）
nodepass "server://0.0.0.0:10101/0.0.0.0:8080?tls=2&crt=/path/to/cert.pem&key=/path/to/key.pem"
```

## 运行模式控制

`mode`参数控制客户端和服务端实例的行为。

### 客户端模式控制
- **模式0**（默认）：自动模式检测
- **模式1**：强制单端转发模式
- **模式2**：强制双端握手模式

### 服务端模式控制
- **模式0**（默认）：自动流向检测
- **模式1**：强制反向模式
- **模式2**：强制正向模式

## 目标地址组与负载均衡

通过逗号分隔多个地址来配置目标地址组，NodePass会自动在这些地址之间进行轮询和故障转移。

```bash
# 服务端配置多个后端目标
nodepass "server://0.0.0.0:10101/backend1.example.com:8080,backend2.example.com:8080?mode=2&tls=1"
```

## URL查询参数配置及作用范围

| 参数      | 说明                 | 默认值    | server | client | master |
|-----------|----------------------|-----------|:------:|:------:|:------:|
| `log`     | 日志级别             | `info`    |   O    |   O    |   O    |
| `tls`     | TLS加密模式          | `0`       |   O    |   X    |   O    |
| `min`     | 最小连接池容量       | `64`      |   X    |   O    |   X    |
| `max`     | 最大连接池容量       | `1024`    |   O    |   X    |   X    |
| `mode`    | 运行模式控制         | `0`       |   O    |   O    |   X    |
| `rate`    | 带宽速率限制 (Mbps) | `0`       |   O    |   O    |   X    |
| `proxy`   | PROXY协议支持        | `0`       |   O    |   O    |   X    |

## 环境变量

可以使用环境变量微调NodePass行为。

| 变量 | 描述 | 默认值 |
|---|---|---|
| `NP_TCP_DATA_BUF_SIZE` | TCP数据传输缓冲区大小 | 16384 |
| `NP_UDP_DATA_BUF_SIZE` | UDP数据包缓冲区大小 | 2048 |
| `NP_HANDSHAKE_TIMEOUT` | 握手操作超时 | 5s |
| `NP_TCP_DIAL_TIMEOUT` | TCP连接建立超时 | 5s |
