# **App Name**: Markdoc Muse

## Core Features:

- Markdown Rendering: Render Markdoc content to HTML. Utilizes a React component to take `*.md` or `*.mdoc` files and display it to the user.
- Dynamic Content: Showcase dynamic content rendering, by allowing users to pass custom properties (like variables, conditional statements and loops) through Markdoc tags, enhancing content presentation.
- Custom Tag/Node Display: Incorporate rendering of new tags/nodes; give practical demonstrations for new structural and semantic HTML.
- Interactive Editor (MVP): Simple editor that renders HTML live based on a Markdoc document.

## Style Guidelines:

- Primary color: Deep Indigo (#663399) for a focused, professional ambiance.
- Background color: Light gray (#F0F0F5), providing a neutral, distraction-free canvas.
- Accent color: Teal (#008080), giving prominent interactive elements clear visual prominence.
- Font pairing: 'Inter' (sans-serif) for body text and 'Space Grotesk' (sans-serif) for headlines.
- Code Font: 'Source Code Pro' for computer code.
- Minimalist icons with a geometric style that align with the professional tone.
- Clean, spacious layout with a focus on readability. Use of whitespace to create a structured and airy feel.
- Subtle animations for transitions and interactive elements to enhance user experience without being distracting.
